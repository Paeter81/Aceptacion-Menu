Calculadora de aceptación de menús

Calcula el porcentaje de residuo del primer plato, segundo plato y guarnición para facilitar el registro de aceptabilidad de menús.

Instrucciones

  1. Selecciona el grupo de comensales.
  2. Introduce los comensales asistentes y, si procede, los no asistentes.
  3. Selecciona cada plato y escribe los kilos sobrantes de cada elaboración.
  4. Pulsa Calcular y rellenar registros para obtener los resultados.
  5. Usa Limpiar todo para comenzar un nuevo registro.
